*Letters From Whitechapel* 1.1.0: the games people play now reach the research collection by themselves, and the first human games have been studied. The game itself plays exactly as in 1.0.0.

**▶ Play online:** https://aceszhenwei.github.io/Letters-From-Whitechapel/ (nothing to install; works on computers and phones)

## For players

- **Your finished games are kept.** Every game you finish, as Jack or as the detectives, is saved in your browser, and the ending dialog says so.
- **Developer Mode's Playtests manager** lets you:
  - export new or selected games as a ZIP, or one game as JSON;
  - import games, each checked by a full replay;
  - delete games.
- **Anonymous Gameplay Research.** When the site is built with a playtest intake, finished games are submitted anonymously to help improve the computer players.
  - **The setting** is on by default, with a notice before you play and a **Research** button to turn it off at any time.
  - **What is sent:** only the game record. No cookie or identifier is sent, nothing about you is stored, and games played while it is off are never sent.
  - **Privacy signals:** browsers that send Global Privacy Control or Do Not Track start with it off.
  - **Until the intake is set up,** the site sends nothing and shows no setting.
- **Unchanged:** the rules, the difficulty levels and the computer players.

## For researchers

- **The human playtest collection** (`research/human-playtests/`):
  - **Records:** each game's full record, checked by full replay in CI;
  - **Batches:** a five-game batch counter and analysis records (`npm run playtests`);
  - **The process:** two tiers, a triage report for each batch and targeted investigations when one is needed ([Human playtests](https://github.com/aceszhenwei/Letters-From-Whitechapel/blob/v1.1.0/docs/playtests.md)).
- **Automatic intake** ([guide](https://github.com/aceszhenwei/Letters-From-Whitechapel/blob/v1.1.0/docs/automatic-playtest-collection.md)):
  - **Storage:** a Cloudflare Worker on the free plan, with a private D1 database.
  - **Checks:** structural only, with rate and size limits, an emergency pause and 365-day retention.
  - **Import:** a daily replay-checked import that opens one pull request and never marks a game as analysed.
- **The first seven human games**, all a person as Jack against Detective AI v3 (Normal). Jack won six. Reports:
  - **[Batch 1 triage](https://github.com/aceszhenwei/Letters-From-Whitechapel/blob/v1.1.0/research/human-playtests/reports/2026-10-11-batch-1.md):** no defect candidates. v3's belief about where people are stays diffuse.
  - **[Coaches](https://github.com/aceszhenwei/Letters-From-Whitechapel/blob/v1.1.0/research/human-playtests/reports/2026-10-11-investigation-coaches.md):** spending every coach early on night 1 does not make v3 lose track of Jack (1,800 computer games).
  - **[The night-4 escape](https://github.com/aceszhenwei/Letters-From-Whitechapel/blob/v1.1.0/research/human-playtests/reports/2026-10-11-investigation-night4.md):** a confirmed flaw in how v3 moves a waited-for victim. It costs no measurable games, so v3 is unchanged.
  - **[How Human Jack moves](https://github.com/aceszhenwei/Letters-From-Whitechapel/blob/v1.1.0/research/human-playtests/reports/2026-10-11-movement.md):** people's routes, coaches, alleys and waiting, compared with the computer Jacks', with route maps.
  - **Seven games, probably from few players:** these describe the games; they are not claims about people in general.
