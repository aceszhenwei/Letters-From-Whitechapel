# Fixtures

`whitechapelR-roads.json` and `whitechapelR-alley.json` are whitechapelR's board graphs (pairs of numbered circles joined by a road or an alley), exported from its `data/roads.rda` and `data/alley.rda` by `../export-whitechapelR-data.R`, for `../compare-maps.js`.

Source: [whitechapelR](https://github.com/bmewing/whitechapelR) 0.3.0, commit `20032d5`, by Mark Ewing. MIT licence, copyright 2018 Mark Ewing. Only this map data is included; none of whitechapelR's code is.
